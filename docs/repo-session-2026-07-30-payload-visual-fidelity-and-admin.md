# 2026-07-30 Payload 视觉保真与后台运营台

## 本次改动

- 将根目录现有 IGNAI 前端明确为 Payload 迁移的视觉事实源。
- 为 M3 增加视觉保真硬门：About 优先，按桌面/平板/手机截图、草稿预览、发布刷新和 reduced-motion 验收。
- 明确 `apps/site` 的通用联调页面不属于生产官网设计，不能继续作为官网视觉扩展。
- 扩展 Payload 后台首页：新增 Pages、加入申请待处理数、常用新建入口、媒体与站点设置入口，以及更清晰的发布流程。

## 面向社区的价值

- 运营者进入后台后可直接开始新建活动、记录、文章、成员，处理加入申请，或维护媒体和站点设置。
- 官网换后台不再等于换审美：已形成的 IGNAI 页面、品牌色、排版和动效将被迁移为新应用组件，再由 Payload 提供内容。

## 可上游化部分

- Payload 后台 Dashboard 的“内容草稿/已发布 + 运营待处理”模式可抽象，但品牌文案、链接与样式为 IGNAI 本地实现。
- 视觉保真迁移阶段门是本项目迁移治理规则，不适合作为 NotionNext 上游改动。

## 剩余工作

- M2：处理 Notion 源数据阻断项、媒体对象存储统一、真实内容导入和复核。
- M3：先抽取原 About 前端与 Payload View Model 对接，再以同一验收门迁移首页和其他路由。
- 首位管理员需要在本地 `/admin` 首次创建页自行设置账号密码；数据库不保存可读密码。
